# 상점 아이템 그림

여기에 파일을 넣으면 상점·정원·보관함에 그림으로 나옵니다.
파일이 없으면 이모지로 대신 나오므로, 없어도 앱은 그대로 돌아갑니다.

지금 앱이 찾는 파일:

| 파일 | 아이템 |
|---|---|
| `ferrari.png` | 페라리 |
| `lamborghini.png` | 람보르기니 |
| `porsche.png` | 포르쉐 |

- **배경이 비치는 PNG**(투명 배경)가 가장 깔끔합니다. 어두운 화면에서도 쓰이기 때문입니다.
- **여백을 바짝 잘라** 주세요. 그림 주변에 흰 여백이 넓으면 작은 칸에서 더 작아 보입니다.
- 한 변 **256px 정도**면 충분합니다.
- 파일을 넣고 `python build.py` 를 다시 돌리면 오프라인 저장 목록에도 자동으로 들어갑니다.
