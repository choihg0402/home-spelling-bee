# 상점 아이템 그림

여기에 파일을 넣으면 상점·정원·보관함에 그림으로 나옵니다.
파일이 없으면 이모지로 대신 나오므로, 없어도 앱은 그대로 돌아갑니다.

지금 앱이 찾는 파일:

| 파일 | 아이템 |
|---|---|
| `ferrari.png` | 페라리 |
| `lamborghini.png` | 람보르기니 |
| `porsche.png` | 포르쉐 |

## 넣는 방법

받아온 그림은 **`items/원본/`** 에 넣습니다. 이름은 아이템 이름과 같게 (`ferrari.jpg` 처럼).
그 다음 `src` 폴더에서:

```
python items.py     # 원본을 다듬어 items/<이름>.png 로 내보냄
python build.py     # 오프라인 저장 목록까지 갱신
```

`items.py` 는 **원본을 절대 고치지 않습니다.** 배경을 지우고 여백을 잘라
한 변 256px 로 줄인 결과만 `items/` 에 새로 씁니다. 마음에 안 들면 다시 돌리면 됩니다.

- 흰 배경이어도 됩니다. 알아서 투명하게 만듭니다.
- 다만 **편집기의 체크무늬가 찍힌 화면 갈무리는 피해주세요.** 그 무늬가 그림의 일부가 되어
  깔끔하게 떨어지지 않습니다. 원본 그대로 받은 파일이 가장 좋습니다.
