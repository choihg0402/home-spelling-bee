# 프로토타입 (껍데기)

기획서 v2.1 §2(연습장/시험장) 구조를 실제 배부 PDF 데이터로 구현한 화면 껍데기.

- `index.html` — 배포용 완성본 (단어 데이터 내장, 단일 파일)
- `index.template.html` — 원본. `/*__WORDS__*/` 자리에 단어 데이터가 들어감
- 데이터 출처: `docs/samples/G2-3_Spelling_Bee_List_1.pdf` (200단어)

## 다시 빌드하기

템플릿을 고친 뒤 단어 데이터를 다시 주입한다.

    python build.py

## 아이패드에서 열기

아티팩트 URL을 사파리로 열고 "홈 화면에 추가".

## 구현된 것 / 안 된 것

구현: 프로필 2개, 퍼즐, 쓰기(타이핑), 말하기 테스트, TTS, 예문 마스킹,
XP/코인/하루 상한, 캐릭터 5단계, 부모 화면(읽기 전용), localStorage 저장

미구현: PDF 업로드 화면(데이터 내장으로 대체), 손글씨 필기, 상점/꾸미기,
복습 큐, 하루 목표, 동기화, 형제 대결
